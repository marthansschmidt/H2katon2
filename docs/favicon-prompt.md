# Favicon

Created with the built-in imagegen tool using the raccoon illustration attached by the user as the character and style reference.

Assets:
- `public/art/favicon-raccoon.png`: 512 × 512 source for future icon sizes.
- `public/favicon.png`: 32 × 32 browser favicon.
- `public/apple-touch-icon.png`: 180 × 180 home screen icon.

## Generation prompt

```text
Use case: logo-brand
Asset type: square website favicon for a friendly Estonian food adventure game.
Input image 1: the user-attached raccoon illustration is the character and style reference.
Primary request: Create a clean favicon derived from this exact cheerful raccoon. Preserve its gray fluffy fur, dark charcoal eye mask, cream muzzle and cheeks, amber eyes, pink inner ears, dark plum outline and happy open smile with pink tongue. Simplify fine fur details into bold readable shapes while keeping the character recognizable.
Composition: a single large centered raccoon head, both ears fully visible, filling roughly 85 percent of the square. No body, paws, food, borders or text. Soft warm ivory background matching the supplied reference, flat and uniform. Crisp polished cartoon illustration, broad high-contrast shapes that remain recognizable at 16x16 and 32x32 pixels.
Constraints: one finished square icon only; no mockup, no icon grid, no lettering, no watermark, no extra elements.
```
