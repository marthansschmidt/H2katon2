# Pixel-art illustrations

## vegetable-toast.webp

Use case: stylized-concept. Asset type: a single transparent pixel-art food illustration for a nutrition game. The supplied food atlas is a STYLE REFERENCE ONLY. Create one appetizing slice of brown wholegrain rye toast topped with pale creamy hummus, green sliced avocado, bright red cherry tomato slices, a few lettuce leaves and tiny sesame seeds. Three-quarter view from above. Match the finely detailed, warm saturated pixel-art shading and dark crisp pixel outlines of the supplied food atlas. One single toast centered with 12% transparent padding, square composition, truly transparent alpha background. Important: entirely plant-based ingredients, NO egg, NO fish, NO meat, NO dairy, no cheese. No text, no labels, no frame, no plate needed, no UI, no baked checkerboard.

Generated with the built-in imagegen tool for this project. The user's `Pixel Raccoon Food Adventure UI.png` was used only as a style reference. UI labels, game values and controls are rendered by React; none are embedded in the images.

Assets are stored in `public/art/`. The character atlas is arranged in two columns and two rows; the food atlas has three columns and five rows. SVG viewBoxes select the individual sprites without editing their image content. The generated PNGs were encoded as WebP at their original dimensions for smaller mobile downloads; the atlases retain transparent alpha.
