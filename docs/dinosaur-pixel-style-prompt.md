# Dinosauruse piksligraafika

Genereeritud sisseehitatud `image_gen` tööriistaga, säilitades läbipaistva tausta. Pesukaru atlas oli stiiliviide ja varasem dinosauruse atlas muutmise alus.

Mängus kasutatav fail: `public/art/dinosaur-pixel-atlas.png` (2172 × 724 px).

## Genereerimisprompt

Use case: style-transfer
Asset type: transparent three-pose dinosaur sprite atlas for an existing pixel-art game.
Input images: Image 1 (raccoon-atlas.webp) is the EXACT art-style reference. Image 2 (dinosaur-atlas.png) is the EDIT TARGET, preserving its dinosaur identity, three poses and three-column composition.
Primary request: redraw the dinosaur atlas in precisely the same handmade low-resolution PIXEL ART style as the raccoon reference. The current dinosaur is too smooth and realistically rendered. Make it clearly belong to the same sprite set as the raccoon.
Style: visible chunky square pixel clusters, stepped stair-shaped silhouette edges, thick dark navy pixel outlines, limited palette, flat blocks of shaded colour with pixel-cluster transitions. Match the raccoon's pixel size, simplified anatomy, chubby proportions, small expressive highlights, modest amber eye highlights, and graphic cartoon shading. Actual pixel-art drawing, not a smooth painting with a pixel filter. Avoid smooth gradients, airbrushing, 3D rendering, glossy plastic lighting, photorealistic detail or shiny lifelike eyes. Make eyes large and cute, but simplified cartoon eyes in the raccoon's style.
Preserve: cute green baby dinosaur, large rounded head, cream belly, rounded darker-green back spikes, chubby little limbs and curved tail, friendly smile, yellow backpack, all three poses in same order. LEFT waves hello with one arm, MIDDLE happily eats from a vegetable bowl with a spoon, RIGHT celebrates with both arms lifted. The three poses must be identical character design, same pixel scale and same baseline.
Composition: ONE wide landscape atlas, three equally-sized cells left to right. Every complete body including tails and waving hands must be contained in its own third, with transparent margins and clear separation. Prefer same 2172 by 724 canvas and similar placement to input target. No additional poses.
Scene/backdrop: transparent alpha background. No black or coloured background, no checkerboard, no floor, no drop shadow, no scenery, no text, no labels, no raccoon in the output.
